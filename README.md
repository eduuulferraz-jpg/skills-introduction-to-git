# Stack Overflown

> Um jogo de lógica e estratégia desenvolvido com HTML, CSS e JavaScript.

## 📋 Sobre o projeto

**Stack Overflown** é um projeto desenvolvido para praticar conceitos de desenvolvimento web, lógica de programação e controle de versão com Git e GitHub.

No jogo, o jogador precisa organizar os blocos que caem na área de jogo de acordo com o padrão apresentado, evitando que a pilha ultrapasse o limite estabelecido.

O projeto foi desenvolvido com foco em uma interface simples, responsiva e intuitiva, proporcionando uma experiência de jogo objetiva e dinâmica.

## 🎯 Objetivos

- Desenvolver um jogo utilizando tecnologias web;
- Praticar lógica de programação com JavaScript;
- Trabalhar com manipulação do DOM;
- Criar uma interface utilizando HTML e CSS;
- Aplicar conceitos de organização de código;
- Utilizar Git para controle de versões;
- Desenvolver um projeto com estrutura profissional.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da aplicação;
- **CSS3** — estilização e layout;
- **JavaScript** — lógica e funcionamento do jogo;
- **Git** — controle de versão;
- **GitHub** — hospedagem e gerenciamento do projeto.

## 🎮 Funcionamento

O jogo apresenta uma sequência de blocos que devem ser organizados de acordo com o padrão definido.

Durante a partida, o jogador precisa tomar decisões rapidamente para posicionar os blocos corretamente.

O objetivo é manter a pilha organizada e impedir que ela ultrapasse o limite da área de jogo.

### Principais elementos

- Sistema de blocos;
- Padrões de organização;
- Área de jogo;
- Sistema de pontuação;
- Condição de derrota;
- Interface interativa.
